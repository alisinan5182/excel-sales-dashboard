# Excel Sales Dashboard

## Project Overview

This is my first Data Analytics project using Microsoft Excel.

The project focuses on analyzing sales data and creating a sales dashboard to understand sales performance and identify useful business insights.

## Tools Used

- Microsoft Excel
- Excel Formulas
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Data Analysis
- Dashboard Creation

## Key Features

- Sales data analysis
- Data cleaning and organization
- Sales calculations using Excel formulas
- Pivot Table analysis
- Pivot Charts
- Data visualization
- Sales performance dashboard
- Business insights from sales data

## Project Objective

The main objective of this project is to transform raw sales data into meaningful information using Microsoft Excel and present the results through a dashboard.

## What I Learned

Through this project, I practiced:

- Cleaning and organizing data
- Using Excel formulas
- Creating Pivot Tables
- Creating charts
- Analyzing sales data
- Building an Excel dashboard
- Presenting data in a simple and understandable way
